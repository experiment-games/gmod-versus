# Contributing

Thanks for your interest in contributing to Half-Life 2: Versus!

## Getting set up

Follow the [Dev Server Guide](docs/dev-server-guide.md) to get a local server running so you can test your changes in-game.

## Before you start coding

* Read [ARCHITECTURE.md](ARCHITECTURE.md) to understand how units and plugins are structured and loaded.
* Read [CONVENTIONS.md](CONVENTIONS.md) for code style (indentation, naming, comments, etc).

## Submitting changes

1. Fork the repository and create a branch for your change.
2. Keep changes focused — separate unrelated fixes into separate pull requests.
3. Test your change on a local dev server before opening a pull request.
4. Open a pull request describing what changed and why.

## Reporting bugs / suggesting features

Please open an issue on GitHub with as much detail as possible (steps to reproduce, expected vs actual behavior, relevant `lua_errors_server.txt`/console output).
